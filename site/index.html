An AI studio — Android, Windows, Linux, macOS & iOS

Build your own AI agents & models

Cairn is a graphical studio, not a ready-made chatbot. You design the flowchart of your project and connect the model you want to each step — any open-source model or any API. Nothing is pre-built inside; everything in it is made by you.

Every model has a role

You build models by their role, then put them to work in your flowchart:

  • LLM
  • Software agent
  • Translator
  • Manager / router
  • Interpreter
  • Image generator
  • Video generator
  • Code writer
  • Voice & music composer

Any open-source model, any API

Ollama and local models like Gemma, or OpenAI-compatible and Anthropic APIs — connect any source to any role.

The flowchart is yours

Add, remove and reorder steps; swap each step's model. Models activate and work exactly according to your flowchart.

In any language

No built-in language pair is assumed. Add any custom language in Settings and use it in projects and translator steps.

Agents learn from you

Write "lessons" for a software agent — text plus screenshots — so it learns the task the way you do it.

Two devices, one studio

Your phone and PC are peers: they sync automatically, and when one device falls short, work is shared between them — home network first, internet last.

Export & backup

Export a project, your models, or the whole studio — and import them anywhere. API keys stay on your device.

How it works

  1. 1

    Build your models

    Define one model per role and connect its source — a local translator, a cloud LLM, an agent for your software…

  2. 2

    Arrange the flowchart

    Order the steps: translator, interpreter, manager, agent, LLM… each step with its own model.

  3. 3

    Run it and watch

    In the test console, give a request and read a short, plain trace of each step — who did what, no walls of text.
